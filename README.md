# Ream Text

**Ream Text** is a lightweight and user-friendly text editor designed as an alternative to Notepad. With a clean interface and essential features, it allows you to quickly write, edit, and save plain text files with ease.

Developed using **Python's Tkinter GUI toolkit**, it’s fast, simple, and easy to run on Windows.

---

## ✨ Features

- 📝 Simple and intuitive text editing
- 💾 Save and open `.txt` files
- 📋 Copy, cut, and paste support
- 🔍 Lightweight and fast
- ⚙️ Comes with an easy-to-install executable setup

## 🚀 Usage

- Launch the application.
- Start typing in the editor area.
- Use the menu options to:
  - **File → Save / Open**: Save your work or open existing `.txt` files.
  - **Edit → Copy / Paste / Cut**: Standard text editing operations.
